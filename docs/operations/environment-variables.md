# Environment variables

Template: `.env.example` (never commit real values). Production values
live on the server in `/etc/twincars/env/manager.env` (mode 600,
root-owned), written by `deploy/scripts/provision.sh`.

## Manager app

| Var                          | Purpose                                                                                                                                   | Dev                     | Prod                                              |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- | ----------------------- | ------------------------------------------------- |
| `DATABASE_URL`               | Postgres connection (postgres-js)                                                                                                         | `.env`                  | manager.env (pod-local postgres)                  |
| `APP_SECRET`                 | better-auth HMAC cookie signing; crypto fallback key                                                                                      | `.env`                  | manager.env                                       |
| `APP_ENCRYPTION_KEY`         | AES-256-GCM key for secrets at rest (eBay tokens) - [[adr-005-encryption-scope]]; falls back to APP_SECRET                                | optional                | generated by provision.sh (64-char hex)           |
| `BETTER_AUTH_URL`            | auth base URL (cookie domain); falls back to `ORIGIN`                                                                                     | `http://localhost:5173` | matches ORIGIN                                    |
| `ORIGIN`                     | SvelteKit origin                                                                                                                          | -                       | `https://tc.ts13.de:5443`                         |
| `HOST` / `PORT`              | adapter-node bind                                                                                                                         | -                       | `0.0.0.0` / `3000`                                |
| `BODY_SIZE_LIMIT`            | adapter-node request cap; the base64 MDB upload needs it                                                                                  | -                       | `67108864` (also `64M` baked into the Dockerfile) |
| `API_TOKENS`                 | Bearer tokens for [[public-rest-api]]; comma/newline/semicolon separated, >= 8 chars each (>= 16 random recommended); empty = fail closed | `.env`                  | manager.env                                       |
| `EBAY_CLIENT_ID`             | eBay App ID                                                                                                                               | optional                | manager.env                                       |
| `EBAY_CERT_ID`               | eBay Cert ID (client secret)                                                                                                              | optional                | manager.env                                       |
| `EBAY_DEV_ID`                | eBay Dev ID (stored on the server for completeness; not read by current code)                                                             | -                       | manager.env                                       |
| `EBAY_RU_NAME`               | OAuth redirect RuName                                                                                                                     | optional                | manager.env                                       |
| `EBAY_VERIFICATION_TOKEN`    | account-deletion challenge secret (32-80 chars `[A-Za-z0-9_-]`); unset = endpoint fails closed                                            | optional                | manager.env                                       |
| `EBAY_DELETION_ENDPOINT_URL` | exact registered URL when it differs from ORIGIN+path                                                                                     | optional                | `https://tc.ts13.de/api/ebay/account-deletion`    |
| `EBAY_ENV`                   | `sandbox` switches eBay world (default production)                                                                                        | optional                | unset                                             |

Do NOT set `NODE_ENV` in `.env` ([[known-constraints]]). The Dockerfile
sets `NODE_ENV=production` in the runtime stage.

## Other containers (`/etc/twincars/env/`)

- `postgres.env`: `POSTGRES_PASSWORD`, `POSTGRES_USER`, `POSTGRES_DB`
  (user/db `twincars`).
- `website.env`: `ORIGIN`, `PORT=3001`, `HOST=0.0.0.0`, plus the
  website's `API_TOKENS`-consuming vars for calling the manager API.
- `registry.env` (template `deploy/env-templates/registry.env`):
  `REGISTRY_HTTP_ADDR=:5001` - auth is enforced by Caddy in front, not
  the registry.

## Env reading conventions in code

Server code reads `process.env[key] ?? env[key]` (`$env/dynamic/private`)
so Vitest `vi.stubEnv` works; see `api-tokens.ts`, `crypto.ts`, eBay
services.
